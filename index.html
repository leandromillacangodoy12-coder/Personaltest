Contamos con la última tecnología

01

Scanner intraoral

Dispositivo portátil utilizado para escanear las superficies intraorales con diferentes fines como diagnosticar, guiar cirugías y replicar preparaciones dentales para diseñar las estructuras protésicas correspondientes.

02

Diseño digital

Software utilizado para la creación, modificación y diseño de estructuras dentales, guías quirúrgicas y planos de relajación, ya sea para su planificación, como para su manufactura.

03

Impresora 3D

Dispositivo utilizado para crear estructuras de resina con diferentes fines, como modelos de estudio para planificación, moldes para creación de estructuras protésicas, guías quirúrgicas y planos de relajación.

04

Fresadora

Máquina utilizada para confeccionar estructuras previamente diseñadas de manera digital a partir de bloques o discos de diferentes materiales como cerámicas y metales.

05

Terminación

Proceso mediante el cual se finalizan las estructuras caracterizándolas según cada caso clínico, donde se incluyen procedimientos como el maquillaje, pulido y terminación.
